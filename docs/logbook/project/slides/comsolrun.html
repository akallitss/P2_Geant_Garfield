COMSOL · how it was run

  1. Licence: COMSOL 6.4 on CVMFS, CERN licence server (licencomsol.cern.ch); needs the COMSOL and AC/DC batch licences, both available
  2. Model to EOS: the 850 MB file, unchanged (/eos/user/a/akallits/p2_sim/comsol)
  3. Inspect in batch: a Java class lists parameters, the two studies, five electrostatics interfaces and the export nodes
  4. Solve class: load → set pitch, height, voltages → solve Study 1 → run the Garfield exports → print the materials
  5. HTCondor job: 8 cores, 24 GB; COMSOL temporary files in the job scratch, model never saved
  6. Solve: h4mm 1.39 M elements, 137 s · h2mm 2.97 M elements, 308 s · whole job 10.5 min
Scripts: scripts/comsol (InspectMeshCell.java, SolveP2MeshCell.java, run_mesh_cell.sh, mesh_cell.sub, README). The 2 mm cell came out meshed twice as finely, likely because the model's element sizes depend on the cell height.
